# 🌱 EcoPulse

An AI-powered environmental issue reporting
and monitoring platform.

## Features
- Report environmental problems
- AI-powered issue analysis
- Severity and priority classification
- Track report status
- Community support for reports

## Tech Stack
- React
- TypeScript
- Node.js
- Express
- SQLite
- Google Gemini AI
- Tailwind CSS

## Installation

1. Clone the repository.
2. Install dependencies:

   npm install

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install` or `npm.cmd install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev` or `npm.cmd run dev`
